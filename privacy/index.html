3. 본인확인과 인증정보

가입 대상은 만 14세 이상입니다. NHN KCP 휴대폰 본인확인 V2를 통해 이름, 생년월일, 성별, 휴대폰번호, CI, DI, 내/외국인 여부 및 통신사를 반환받습니다. CI/DI는 실제 제공되는 항목입니다. 모든 국가·해외 전화번호의 인증을 보장하지 않으며 세부 지원 범위는 제공 수단에 따릅니다.

CI는 동일인·중복계정 확인에 필요한 변환 식별값(HMAC)으로 바꾸어 계정에 연결합니다. 원본 CI와 DI를 장기 저장하지 않으며, 변환 식별값도 개인정보 보호 대상입니다. 생년월일은 만 14세 이상 판단을 위해 일시 처리하고 짧은 유효기간의 암호화된 인증 확인값으로 전달하며, DB에는 생년월일 자체 대신 연령 자격 확인 시각을 기록합니다.

이름·성별·휴대폰번호·DI·내/외국인 여부·통신사는 본인확인 결과에 포함되어 수신되지만 현재 계정 연결 처리에서 개별 저장하지 않습니다. 복호화한 결과 원문 전체도 DB에 보관하지 않습니다. 사용한 정보는 일시적인 처리 후 별도 원문 보관 없이 처리를 종료합니다.

본인확인 거래를 이어가기 위한 기술적 거래등록키(reg_cert_key), 거래 상태·주문번호·유효기간 및 검증용 참조정보는 임시 저장합니다. 이 키는 CI/DI처럼 사람을 장기 식별하는 계정 연결값과 다릅니다.

MEMONARY 이용약관·개인정보 처리 안내 확인 이후 진행하는 KCP 본인확인 단계에서는 KCP 및 통신사의 개인정보 이용동의, 고유식별정보처리동의, 서비스·통신사 약관과 해당 알뜰폰의 제3자 제공동의가 별도로 표시됩니다. 이 동의를 MEMONARY 자체 동의로 대신하거나 약관 본문에 복사하지 않습니다.

패스키 비밀키와 기기 생체인증 원본은 MEMONARY 서버로 보내는 인증 자료가 아닙니다. 서버는 공개키 기반 인증 정보를 사용합니다. 보안 이메일을 공개 프로필·사용자 검색·친구 추천에 사용하지 않습니다.

iOS 및 Google Play 신규 유료구매의 만 19세 이상 확인을 위해 필요 시 KCP 본인확인을 다시 진행합니다. 생년월일은 일시 처리하고, 현재 계정에는 확인 시각·연령정책 버전·검증 제공업체 종류만 기록합니다. 이 절차를 위해 DOB 원문·CI/DI·본인확인 원문 응답을 새로 장기보존하지 않습니다. 계정 최종 삭제 시 이 현재 계정용 확인 사실도 삭제합니다. 기존 구매 복원은 신규구매 연령 확인 대상이 아닙니다.

4. 이용자 간 공유와 제3자 제공

이용자가 선택한 공개 범위, 대화·약속·Memory의 현재 참여 권한에 따라 콘텐츠가 다른 이용자에게 표시됩니다. 전체 공개 Memory는 완료 상태와 현재 권한을 충족하면 프로필에 자동 표시될 수 있습니다. 공유하기 전에 공개 범위를 확인해 주세요. 사진·본문에 건강이나 사생활 등 민감한 내용이 포함되면 선택한 공개 범위에 따라 다른 이용자에게 보일 수 있습니다. 비공개 범위를 선택하거나 해당 내용을 삭제·가림 처리한 뒤 게시해 주세요.

이용자 간 공유와 외부 업체의 서비스 처리는 구분합니다. 독립적인 제3자 제공이 필요한 경우 제공받는 자·목적·항목·보유기간과 동의 또는 다른 법적 근거를 안내합니다. NHN KCP의 휴대폰 본인확인은 MEMONARY가 맡기는 처리위탁이며 일반적인 제3자 제공으로 분류하지 않습니다. KCP 화면의 통신사·알뜰폰 제3자 제공동의는 이 위탁관계와 구분합니다.

8. 탈퇴와 파기 방법

앱에서 탈퇴를 요청하면 일반 서비스 접근이 제한되고 30일의 취소 가능 대기를 거칩니다. 기한 이후 최종 삭제 처리와 결과 기록이 완료되어야 탈퇴가 완료됩니다. 요청 즉시 또는 30일째 같은 순간에 모든 정보가 사라지는 것은 아닙니다. 앱 밖 요청은 계정 삭제 안내를 이용할 수 있습니다.

Firebase 삭제 요청 수락을 확인한 뒤 서버 알림 등록 연결을 제거하고 실패 시 재처리하는 절차를 적용합니다. 다른 계정이 현재 이용하는 설치정보는 보호합니다. API 수락은 공급자의 모든 사본이 물리적으로 삭제됐다는 의미가 아닙니다.

별도 보존은 대상·근거·기간을 구분하고 일반 서비스와 분리하여 접근을 제한합니다. 전자 파일은 복구·재생할 수 없도록 삭제하고 종이 자료가 생기면 분쇄 등 안전한 방법으로 파기합니다. 화면 숨김·삭제 표시와 저장 데이터 파기는 구분합니다.

운영 DB 삭제와 기존 백업의 만료는 다른 사건입니다. 복원 때 삭제된 계정·정보가 다시 서비스되지 않도록 대조하며, 탈퇴 완료 안내는 모든 백업이나 법정 거래기록의 소멸을 뜻하지 않습니다. 사업자 서류는 증빙 안내에 따라 원본·미리보기 및 별도 결과기록을 나누어 처리합니다.
